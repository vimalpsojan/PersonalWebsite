Outside work

Homelab experiments

A small place to try things, run useful services and learn how the pieces fit together.

The lab combines experiments in Linux, networking, storage and self-hosting with services used day to day.

The setup

Proxmox VE hosts virtual machines and containers. Docker and Portainer handle applications, with TrueNAS providing storage.

Running LLMs locally

Ollama and Open WebUI provide a local language model environment. A shared model library on the NAS lets multiple Ollama instances use the same models without storing duplicate copies on each machine. Custom Ollama model configurations are available through the same library.

Areas of exploration

Notebooks

JupyterHub provides notebooks for trying ideas and running small experiments.

Home automation

Homebridge connects smart devices to Apple Home, including devices without native HomeKit support.

Everyday uses

Self-hosted media and personal finance services give the lab everyday uses.

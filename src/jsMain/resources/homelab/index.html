Outside work

Homelab experiments

A small place to try things, run useful services and learn how the pieces fit together.

I use the lab to explore Linux, networking, storage and self-hosting, with services that are useful day to day.

The setup

Proxmox VE provides the foundation, with virtual machines and containers for self-hosted services. I use Docker and Portainer to manage applications, and TrueNAS for storage.

Running LLMs locally

I use Ollama to run language models in my homelab, with Open WebUI as a browser interface. The model files live on my NAS, so I can share them with other Ollama systems on the network instead of keeping a separate copy on each machine.
